ORBITAL 0.1.0 "First Orbit": a two-body orbit propagator built from first principles, with its accuracy validated against the exact circular-orbit solution.

## Capabilities

- Newtonian point-mass gravity, a = −μr/|r|³, with WGS 84 constants (NGA.STND.0036).
- Fixed-step semi-implicit (symplectic) Euler propagation in a 2D Earth-centred inertial frame, SI units, float64.
- Explicit endpoint policy (whole steps, reported end time), surface-impact detection, and an error on non-finite states.
- Diagnostics: radius, speed, specific energy, angular momentum, and first-period detection with interpolation.
- A to-scale trajectory plot and a reference-case report (`scripts/first_orbit.py`).
- Strict input validation; a physics core that depends only on NumPy and is independent of any frontend.

## Validation

Reference case: 400 km circular orbit, Δt = 1 s, 10 orbits (55,536 steps). Measured at commit `dcaf079` on Python 3.12.16, NumPy 2.5.5, arm64 macOS. There are no physics changes between that commit and this release.

| Check | Measured | Tolerance |
| --- | --- | --- |
| T3 angular momentum, max \|Δh/h₀\| | 8.66 × 10⁻¹⁵ | ≤ 10⁻¹⁰ |
| T4 radius, max \|Δr\|/r₀ (orbit 10 ÷ orbit 1 = 1.00) | 5.66 × 10⁻⁴ | ≤ 10⁻³ |
| T5 energy, max \|Δε/ε₀\| (orbit 10 ÷ orbit 1 = 1.00) | 1.28 × 10⁻⁶ | ≤ 10⁻⁵ |
| T6 period error | 9.07 × 10⁻⁷ | ≤ 10⁻⁵ |
| T7 position error after one orbit | 38.7 m | ≤ 100 m |
| T8 first-order convergence (error ratio for 10× Δt) | 10.1 | 9 to 11 |

All 12 acceptance tests and 166 automated tests pass on Python 3.11 and 3.12. Deliberate-bug checks confirm the tests detect real faults. In particular, a 0.01% error in gravity is invisible to the conservation checks and is caught only by the analytical comparisons. Full details: [`docs/validation/v0.1-circular-orbit.md`](../validation/v0.1-circular-orbit.md).

## Limitations

- Validated for one circular orbit at 400 km only. Elliptical orbits and other altitudes are not yet validated.
- Idealised physics: point-mass Earth, 2D, no J2, drag, third bodies or radiation pressure. Not a predictor of real spacecraft.
- First-order integrator: along-track error grows by about 39 m per orbit at Δt = 1 s.
- Impact time is approximate, because impact is detected at step boundaries only.
- No interactive interface, maneuvers or AI features. Those are later milestones.
